# Agents run as Orca workers in a Workspace linked to a Linear issue

Each Task starts with an Orca workspace linked to one Linear issue. A Claude Code session in that workspace runs the Coordinator, and the Coordinator starts each Agent as a supervised Orca worker: a separate Claude Code session in the same workspace that talks to the Coordinator through Orca orchestration messages. We rejected Claude Code subagents because a subagent cannot talk to the user, which Planning needs, and agent teams because they are experimental and teammates do not survive `/resume`. A worker does its whole Agent's work itself and starts no subagents either, so each Agent's work stays in one session the user can open. The cost is a hard dependency on Orca, Linear and Claude Code as the only agent.
