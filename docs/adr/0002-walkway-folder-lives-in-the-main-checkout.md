# Walkway files live in one git-ignored folder in the main checkout

The Product Context and the other Walkway files live in a `.walkway/` folder at the root of the project's main checkout, so they are never versioned and can be updated at any time. The folder is ignored twice: in the repository's shared `info/exclude`, which every checkout reads at once, and in `.gitignore`, committed with the first Task's PR. Every Workspace is a git worktree that does not receive ignored files, so each Step finds this single folder through `git rev-parse --git-common-dir` instead of using a `.walkway/` of its own. We rejected versioning the folder, because an update would only reach other Tasks after a merge, and a per-Workspace copy, because each Task would lose the Product Context. The cost is no history or review, and two parallel Tasks can overwrite each other's update.
