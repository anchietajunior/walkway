How to read this section
  • Property: an AC written as a rule a machine can check: given a state, when an action happens, then the customer observes a result.
  • Generated-input test: a test that builds many random inputs from a recorded seed and checks the property on each one.
  • Changed lines covered: changed lines that run during the AC tests. A line no test runs is a line no test protects.
  • Mutation probe: a small bug put in the code on purpose. Killed means a test caught it; equivalent means the edit cannot change any behavior.
  • Layer 2: a TLA+ model of the risky behavior. TLC tries every order of its steps and checks the properties in every state it reaches.
